# Ankit Rai Portfolio

A responsive AI/ML portfolio built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Before deployment
1. Add your resume as `Ankit_Rai_Resume.pdf` in this folder.
2. Add project GitHub/demo links when ready.
3. Deploy the folder to GitHub Pages, Netlify or Vercel.
